# CAFE MOCA Admin Frontend

Figma 기반 운영진 사이트 프론트엔드 완성본입니다.

## 실행

```bash
npm install
npm run dev
```

## 포함 화면

- 운영진 로그인
- 대시보드
- 부스 참여 처리
- 참여자 관리
- 협찬 재고
- 행사 진행표
- 성과 보기
- 행사 진행 상세 02 온라인 결과 확인 · 영수증
- 행사 진행 상세 03 키워드 맞추기 게임
- 행사 진행 상세 04 카페 정보 우선순위 정하기
- 행사 진행 상세 05 럭키드로우
- 행사 진행 상세 06 협찬 · 상품 지급
- 행사 진행 상세 07 예외 처리
- 행사 진행 상세 08 마감

현재는 프론트엔드 mock data 기준입니다. Supabase 인증/DB 연동은 별도 단계입니다.


## 네비게이션 수정본

- 모든 운영진 화면에서 동일한 좌측 네비게이션 유지
- 네비게이션 열기/닫기 지원
- 닫힌 상태에서도 72px 레일이 남아 다시 열 수 있음
- 부스 참여에서도 네비게이션이 사라지지 않음
- 행사 진행표와 상세 02~08에서도 네비게이션 고정
- 상세보기 시 오른쪽 콘텐츠만 변경
- 상세 화면의 왼쪽 세로 강조색 바 제거


## iPad 반응형 수정

- 행사 진행표 상세보기는 페이지 전환 없이 동일 화면에서 동작
- 넓은 화면에서는 진행표 왼쪽 + 상세 패널 오른쪽
- 1024px 이하에서는 선택한 단계 바로 아래에 상세 내용 펼침
- 진행표 블록 너비를 축소하고 유동형 레이아웃으로 변경
- 사이드바 토글 버튼 잘림 수정
- iPad에서는 사이드바 폭 축소, 더 작은 화면에서는 64px 축약 레일 + 열림 시 오버레이
- 대시보드/참여자/협찬재고/부스/성과보기 모두 반응형 폭으로 수정
